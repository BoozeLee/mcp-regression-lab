# Security Policy

## Supported versions

Security fixes are provided on the latest stable v1 release.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting for this repository. Do not disclose vulnerabilities,
MCP tokens, model keys, API tokens, server credentials, or customer contract data in public issues,
pull requests, or discussions.

Include a minimal reproduction, affected version or commit SHA, impact, and any mitigation you
already applied. Reports are acknowledged after triage; fixes are released in a new immutable
versioned release.
